# v1.3.0 — 仪表盘新增「鹈鹕测试」提示词一键复制

## ✨ 新增功能

- **两种触发方式**：点击「提示」按钮，或直接点击提示文本芯片「画一只骑自行车的鹈鹕」，均会把测试提示词复制到剪贴板。
- **明确的视觉反馈**：复制成功弹出绿色 Toast「已复制：画一只骑自行车的鹈鹕」，按钮同时短暂变绿；复制失败弹出红色错误 Toast（例如「复制失败：浏览器未授权剪贴板访问」），不会静默失败。
- **剪贴板两级策略**：优先 `navigator.clipboard.writeText`（安全上下文可用，`127.0.0.1` 属于安全上下文）；非 HTTPS 局域网地址、旧 WebView 自动回退到隐藏 `textarea` + `document.execCommand('copy')`，并针对 iOS 设置 `setSelectionRange`。
- **不干扰页面**：复制前保存、复制后还原用户当前选区；提示面板与 Toast 位于 `#app` 容器之外，30 秒自动刷新的整体重绘不会重建面板、不会丢失事件监听器；复制为纯前端动作，零网络请求。
- **移动端适配**：≥40px 触控目标、`touch-action: manipulation` 消除点按延迟、`-webkit-tap-highlight-color: transparent`、`user-select: none` 防长按误选、面板自动换行、Toast `max-width: 88vw`。

# v1.3.0 — One-Click "Pelican Test" Prompt Copy in the Dashboard

## ✨ New Features

- **Two triggers**: click the hint button, or click the prompt chip "draw a pelican riding a bicycle" — either copies the test prompt to the clipboard.
- **Clear visual feedback**: a green toast "Copied: draw a pelican riding a bicycle" plus the button briefly turning green on success; a red error toast (e.g. "Copy failed: clipboard access not authorized by the browser") on failure — never a silent failure.
- **Two-level clipboard strategy**: `navigator.clipboard.writeText` first (available in secure contexts; `127.0.0.1` qualifies); non-HTTPS LAN addresses and old WebViews automatically fall back to a hidden `textarea` + `document.execCommand('copy')`, with `setSelectionRange` set for iOS.
- **Non-intrusive**: the user's current selection is saved before copying and restored afterwards; the hint panel and toast live outside the `#app` container, so the 30-second auto-refresh never rebuilds them or drops their event listeners; copying is a pure front-end action with zero network requests.
- **Mobile-friendly**: ≥40px touch targets, `touch-action: manipulation` to remove tap delay, `-webkit-tap-highlight-color: transparent`, `user-select: none` against long-press selection, auto-wrapping panel, and `max-width: 88vw` toasts.
