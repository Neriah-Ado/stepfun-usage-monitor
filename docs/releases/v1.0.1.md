# v1.0.1 — 首个公开发布版本

StepFun（阶跃星辰）API Token 用量的本地监控插件。通过本地反向代理接入，**零 npm 依赖、数据全本地**，兼容几乎所有 OpenAI 兼容 Agent。

## ✨ 新增功能

- **本地反代接入**：客户端只需把 Base URL 改为 `http://127.0.0.1:8787/v1`，路径与 API Key 不变即可统计；覆盖 ZCode、Cline、Roo Code、Continue、Cursor、Cherry Studio、ChatBox、LobeChat、Open WebUI、Dify、LangChain/LiteLLM、openai SDK、curl 等。
- **流式用量解析**：自动为 `stream=true` 请求注入 `stream_options.include_usage=true`（StepFun 流式默认不返回 usage），上游拒绝时自动回退重发。
- **本地仪表盘**：纯静态无 CDN，含每日堆叠柱状图、模型/客户端排行、最近请求明细。
- **MCP 查询工具**：`query_stepfun_usage(days, group)`，支持在 ZCode 等 MCP 客户端中对话式查询用量。
- **隐私优先**：仅记录时间、客户端、模型、token 数、状态码、耗时；不记录请求/响应正文与 API Key。

# v1.0.1 — First Public Release

A local monitoring plugin for StepFun API token usage. It hooks in as a local reverse proxy — **zero npm dependencies, all data stays local** — and is therefore compatible with virtually any OpenAI-compatible agent.

## ✨ New Features

- **Local reverse-proxy integration**: point the client's Base URL at `http://127.0.0.1:8787/v1` and usage is tracked with paths and API keys unchanged; covers ZCode, Cline, Roo Code, Continue, Cursor, Cherry Studio, ChatBox, LobeChat, Open WebUI, Dify, LangChain/LiteLLM, the openai SDK, curl, and more.
- **Streaming usage parsing**: automatically injects `stream_options.include_usage=true` into `stream=true` requests (StepFun does not return usage for streams by default) and retries with the original body if the upstream rejects it.
- **Local dashboard**: fully static with no CDN, including a daily stacked bar chart, model/client rankings and recent request details.
- **MCP query tool**: `query_stepfun_usage(days, group)` for conversational usage queries in MCP clients such as ZCode.
- **Privacy first**: records only timestamp, client, model, token counts, status code and latency — never request/response bodies or API keys.
