# v1.5.9 — ZCode 官方插件格式 + Agent 页面吸附弹窗

## ✨ 新增功能

### 1. ZCode 官方插件市场结构

- 新增根目录 `marketplace.json`（市场清单）与 `plugins/stepfun-usage-monitor/`（标准插件目录），完全遵循 [ZCode 插件官方规范](https://zcode.z.ai/cn/docs/plugin)：
  - `.zcode-plugin/plugin.json`：`name` / `version` / `description` / `author` / `homepage` / `repository` / `license` / `keywords` / `commands` / `mcpServers`；
  - `commands/sfm.md`：标准命令（frontmatter `description` + `argument-hint`），在 ZCode 中输入 `/sfm` 即可一键查询用量并拉起吸附弹窗；
  - `.mcp.json`：stdio MCP 服务器配置，通过 `${CLAUDE_PLUGIN_ROOT}` 模板变量指向仓库统一入口 `bin/cli.mjs --mcp`，服务名自动命名空间为 `plugin:stepfun-usage-monitor:stepfun-usage`。
- 移除旧的非标准 `zcode/command-sfm.md`；npm 包 `files` 字段同步更新（`npx` 直载用户同样获得完整插件文件）。

### 2. Agent 页面吸附弹窗（ZCode 无 UI 挂载点的替代方案）

- 新增 `lib/open-panel.mjs`（零依赖）：探测本机 Edge / Chrome → 以 `--app` 无边框窗口打开 `?layout=panel`，按主屏分辨率自动停靠**底部居中**（1000×190）；本地代理未运行时自动拉起；弹窗已打开时重复调用只聚焦、不重开（Windows 标题唤焦）。
- MCP 新增 `open_monitor_panel` 工具：`mode="panel"`（默认，吸附弹窗）/ `mode="full"`（独立浏览器完整页），支持 `dryRun` 自检；`bin/cli.mjs` 新增 `--panel [panel|full]` 参数，`open-panel.cmd` 行为不变。
- `/sfm` 命令逻辑优化：先拉起吸附弹窗，再按天 / 模型 / 客户端 / 服务商分组汇报用量表格。

### 3. 「全量显示」按钮（弹窗 → 独立浏览器页）

- 底栏（吸附弹窗）标题栏新增「⤢ 全量显示」按钮：一键以独立浏览器页面打开完整仪表盘。
- 嵌入布局窗口标题改写：底栏为「StepFun 用量监控 · 吸附弹窗」，小窗为「StepFun 用量监控 · 小窗」，便于任务栏区分与唤焦。

## 🐛 修复

- **底栏布局没有任何可见入口按钮**：`?layout=panel` 下整个性能档位栏 `#perf-bar` 被隐藏，其中的「↗ 浏览器页」按钮实际不可见（原测试断言因父元素隐藏而恒真）。现底栏标题栏常驻「⤢ 全量显示」独立入口，`browser-smoke` 同步改为真实可见性断言。
- `npm pack` 产物随插件结构更新：移除 `zcode/`，新增 `marketplace.json` 与 `plugins/`（含 `.zcode-plugin/`、`.mcp.json`）。

# v1.5.9 — Official ZCode Plugin Format + Agent-Page Docked Popup

## ✨ New Features

### 1. Official ZCode plugin marketplace structure

- New root `marketplace.json` (marketplace manifest) and `plugins/stepfun-usage-monitor/` (standard plugin directory), fully following the [official ZCode plugin spec](https://zcode.z.ai/cn/docs/plugin):
  - `.zcode-plugin/plugin.json`: `name` / `version` / `description` / `author` / `homepage` / `repository` / `license` / `keywords` / `commands` / `mcpServers`;
  - `commands/sfm.md`: standard command (frontmatter `description` + `argument-hint`) — type `/sfm` in ZCode to query usage and raise the docked popup in one step;
  - `.mcp.json`: stdio MCP server config that points at the repo's unified entry `bin/cli.mjs --mcp` via the `${CLAUDE_PLUGIN_ROOT}` template variable (the service is auto-namespaced as `plugin:stepfun-usage-monitor:stepfun-usage`).
- Removed the legacy non-standard `zcode/command-sfm.md`; the npm package's `files` field is updated in step (npx direct-load users get the full plugin files too).

### 2. Agent-page docked popup (the answer to ZCode having no UI mount point)

- New `lib/open-panel.mjs` (zero dependencies): probes the local Edge / Chrome, opens `?layout=panel` as a borderless `--app` window, and auto-docks it **bottom-center** based on the primary screen resolution (1000×190); the local proxy is started automatically when not running; repeated calls only focus the already-open popup instead of reopening it (Windows title activation).
- New MCP tool `open_monitor_panel`: `mode="panel"` (default, docked popup) / `mode="full"` (standalone browser full page), with `dryRun` self-check support; `bin/cli.mjs` gains `--panel [panel|full]`. `open-panel.cmd` behaves as before.
- `/sfm` command reworked: raise the docked popup first, then report usage grouped by day / model / client / provider.

### 3. "Full Display" button (popup → standalone browser page)

- The bottom-bar (docked popup) title row gains a "⤢ Full Display" button that opens the complete dashboard in a standalone browser page.
- Embedded-layout window titles rewritten: the bottom bar becomes "StepFun Usage Monitor · Docked Popup" and the small window "StepFun Usage Monitor · Small Window", making them easy to tell apart and activate from the taskbar.

## 🐛 Fixes

- **The bottom-bar layout had no visible entry button at all**: under `?layout=panel` the entire performance-mode bar `#perf-bar` is hidden, so the "↗ browser page" button inside it was effectively invisible (the original test assertion was vacuously true because the parent was hidden). The bottom-bar title row now always shows the "⤢ Full Display" standalone entry, and `browser-smoke` asserts real visibility accordingly.
- `npm pack` output follows the plugin restructure: `zcode/` removed, `marketplace.json` and `plugins/` (including `.zcode-plugin/` and `.mcp.json`) added.
