# v1.5.0 — GitHub URL 直载 + 三种浏览布局 + VS Code 系扩展

## ✨ 新增功能

### 1. GitHub URL 直载（免 clone / 免安装）

```bat
npx -y github:Neriah-Ado/stepfun-usage-monitor            :: 启动监控代理 + 仪表盘
npx -y github:Neriah-Ado/stepfun-usage-monitor --mcp      :: MCP Server 模式（Agent 对话查询）
```

- `bin/cli.mjs` 统一入口：默认代理 / `--mcp` 双模式，支持 `--port` / `--data-dir` / `--version` / `--help`。
- **统一数据目录解析**（`lib/paths.mjs`，proxy / mcp-server / stats 三入口一致）：`DATA_DIR` 环境变量 > `~/.stepfun-usage-monitor/` > 包内 `data/`（历史数据原地兼容）；npx 运行时数据不再落入 npm 缓存目录，缓存清理不丢数据。
- ZCode MCP 配置：设置 → MCP 服务器，JSON 填入 `"args": ["-y", "github:Neriah-Ado/stepfun-usage-monitor", "--mcp"]`。

### 2. 仪表盘三种浏览布局（`?layout=full|window|panel`）

| 布局 | 入口 | 内容 |
|---|---|---|
| 完整页 | `/` | 全部功能 |
| 小窗 | `/?layout=window` 或 `open-window.cmd` | KPI + 图表（隐藏长表格），Chrome/Edge `--app` 无边框窗口 |
| 底部横条 | `/?layout=panel` 或 `open-panel.cmd` | 超紧凑 KPI 横条，走 lite 精简载荷 |

- head 内联脚本先于样式写入 `data-layout`，嵌入模式无 FOUC；三种布局右上角一键互切；嵌入模式提供「↗ 浏览器页」独立页入口。

### 3. VS Code 系 IDE 扩展（VSIX）

- 附件 `stepfun-monitor-1.5.0.vsix`：底边栏 Webview 面板 / 小窗编辑器 / 独立浏览器三种打开方式，外加状态栏今日 tokens。
- 代理未运行时自动 `npx` 从 GitHub 拉起（可配置关闭）。
- 零依赖 VSIX 打包器（`test/build-vsix.mjs`，ZIP 写入 + CRC32 + 自校验读回）。

### 4. ZCode 原生支持

- `zcode/command-sfm.md`：放入 ZCode 自定义命令获得 `/sfm` 对话式查询指令。

## 🐛 修复

- 带查询串的根路径（如 `/?layout=panel`）此前会穿透转发到上游（路由仅精确匹配 `url === '/'`），现按 pathname 匹配本地路由。

# v1.5.0 — GitHub URL Direct Load + Three Browsing Layouts + IDE Extension

## ✨ New Features

### 1. GitHub URL direct load (no clone / no install)

```bat
npx -y github:Neriah-Ado/stepfun-usage-monitor            :: start the proxy + dashboard
npx -y github:Neriah-Ado/stepfun-usage-monitor --mcp      :: MCP Server mode (chat queries)
```

- `bin/cli.mjs` unified entry: proxy mode by default, `--mcp` for MCP mode, plus `--port` / `--data-dir` / `--version` / `--help`.
- **Unified data-directory resolution** (`lib/paths.mjs`, consistent across proxy / mcp-server / stats): `DATA_DIR` env var > `~/.stepfun-usage-monitor/` > in-package `data/` (legacy data stays in place). npx runtime data no longer lands in the npm cache, so clearing the cache never loses history.
- ZCode MCP setup: Settings → MCP Servers, with `"args": ["-y", "github:Neriah-Ado/stepfun-usage-monitor", "--mcp"]`.

### 2. Three dashboard browsing layouts (`?layout=full|window|panel`)

| Layout | Entry | Content |
|---|---|---|
| Full page | `/` | Everything |
| Small window | `/?layout=window` or `open-window.cmd` | KPIs + chart (long tables hidden), Chrome/Edge `--app` borderless window |
| Bottom bar | `/?layout=panel` or `open-panel.cmd` | Ultra-compact KPI strip on the lite payload |

- An inline head script writes `data-layout` before styles, so embedded modes have no FOUC; all three layouts switch between each other from the top-right corner; embedded modes provide a "↗ browser page" standalone entry.

### 3. IDE extension for VS Code-family editors (VSIX)

- Attached `stepfun-monitor-1.5.0.vsix`: bottom-bar Webview panel / editor window / standalone browser, plus a status-bar item for today's tokens.
- Automatically pulls the proxy up via `npx` from GitHub when it is not running (configurable).
- Zero-dependency VSIX builder (`test/build-vsix.mjs`: ZIP writing + CRC32 + read-back self-verification).

### 4. Native ZCode support

- `zcode/command-sfm.md`: drop into ZCode custom commands to get the `/sfm` chat-query command.

## 🐛 Fixes

- Root paths with a query string (e.g. `/?layout=panel`) used to be forwarded through to the upstream (routing only matched `url === '/'` exactly); local routing now matches by pathname.
